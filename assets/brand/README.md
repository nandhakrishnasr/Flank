# Flank mascot and logo

An original bird mascot. A flank is also the side of a bird's body, and the bird perches on a ledge that stands for the dock.

| File | Use |
|---|---|
| `flank-mascot.svg` / `-1024.png` | Full mascot: website, about screen, empty states, store listing |
| `flank-app-icon.svg` / `-1024.png` | App icon on a cream rounded square (transparent corners) |
| `flank.ico` | Windows icon with 16, 24, 32, 48, 64, 128 and 256 px sizes, built from the app icon |
| `flank-glyph.svg` / `-1024.png` | One-colour mark that follows `currentColor`, for the tray and monochrome uses |

Colours: blue #2F4BFF, deep blue #1E34C9, wing highlight #5B74FF, beak and feet #F5A524, belly #FBFAF7, ink and ledge #1F1E1B, cheek #FF8A7A.

Notes:
- The glyph has fine details (wing outline, feet). Use it at 24 px or larger. For a 16 px tray icon, make a simplified version with just the body, beak and eye.
- The SVGs use basic shapes only, so they can be edited in any vector tool.
